# Contributing

Contributions are welcome when they preserve the project's authorized security-testing purpose and architecture.

## Before opening a pull request

- [ ] Read `AGENTS.md` and `ARCHITECTURE.md`
- [ ] Keep the change focused
- [ ] Add/adjust tests
- [ ] Update relevant docs
- [ ] Update `STATUS.md` if feature state changed
- [ ] Confirm the project builds
- [ ] Document the source/provenance of any WPS algorithm
- [ ] Document license and pinned revision for third-party native code

Do not paste code from an incompatible license into this repository.
